# Slider Flask

Proyecto desarrollado utilizando Python Flask,
HTML, CSS, Tailwind CSS v4 y JavaScript.

## Objetivo

Desarrollar un slider dinámico, moderno y responsive
que permita visualizar diferentes imágenes.

## Tecnologías utilizadas

- Python
- Flask
- HTML5
- CSS3
- Tailwind CSS v4
- JavaScript
- Git
- GitHub

## Funcionalidades

- Slider con 8 imágenes
- Cambio automático cada 5 segundos
- Botón anterior
- Botón siguiente
- Indicadores
- Contador de imágenes
- Botón de pausa y reproducción
- Navegación con teclado
- Diseño responsive
